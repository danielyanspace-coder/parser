# License server (Message Sender)

Небольшой сервер без зависимостей (только встроенные модули Node.js), который
выдаёт токены доступа и управляет ими через веб-админку. Приложение работает,
только пока у него есть действующая **лицензия** — короткоживущий «пропуск»,
который сервер выдаёт по токену и **подписывает** своим закрытым ключом.

## Как это защищает от «бесконечного» использования

1. Приложение при активации и затем периодически шлёт токен на `/api/validate`.
2. Если токен есть и **включён**, сервер возвращает лицензию со сроком (по
   умолчанию 24 часа), подписанную ECDSA-ключом сервера.
3. Приложение проверяет подпись **встроенным открытым ключом** и работает, пока
   лицензия не истекла. Не смогло обновить (нет сети / токен выключен) →
   по истечении срока функционал отключается сам.

Почему обойти обычными способами нельзя:

- **Отключить интернет** — лицензия протухнет за 24 часа, и приложение встанет.
- **Подделать ответ сервера** — не пройдёт проверку подписи (нужен закрытый
  ключ сервера, которого нет на устройстве).
- **Отозвать токен** — в админке жмёте «Выключить», сервер перестаёт выдавать
  лицензии, и все устройства с этим токеном отключаются в течение срока (≤24 ч).

> Полностью «непробиваемой» защиты на чужом устройстве не существует: тот, у кого
> есть APK и навыки реверс-инжиниринга, теоретически может пропатчить проверку.
> Но для обычных пользователей это надёжный контролируемый доступ с мгновенным
> отзывом из админки.

## Запуск

Нужен Node.js 18+. Зависимостей нет.

```bash
cd server
ADMIN_PASSWORD='придумайте-пароль' node server.js
```

Переменные окружения:

| Переменная       | По умолчанию | Назначение                                   |
|------------------|--------------|----------------------------------------------|
| `ADMIN_PASSWORD` | — (обязат.)  | Пароль для входа в админку                    |
| `ADMIN_USER`     | `admin`      | Логин админки                                 |
| `PORT`           | `8080`       | Порт                                          |
| `LEASE_TTL_MS`   | `86400000`   | Срок лицензии в мс (24 ч). Меньше = быстрее отзыв |

При первом запуске в `data/keys.json` создаётся пара ключей, а открытый ключ
печатается в консоль (и доступен на `/admin/pubkey`).

## Настройка приложения

1. Запустите сервер и скопируйте **открытый ключ** (из консоли или `/admin/pubkey`).
2. В `app/build.gradle.kts` пропишите:
   - `SERVER_URL` — публичный `https`-адрес вашего сервера;
   - `LICENSE_PUBLIC_KEY` — скопированный ключ.
3. Соберите APK. Пользователь вводит выданный вами токен и жмёт «Активировать».

## Хостинг

Подойдёт любой VPS или бесплатные платформы (Render, Railway, Fly.io и т.п.).
Важно:

- **Обязательно HTTPS** — иначе токен можно перехватить в сети. На бесплатных
  платформах HTTPS есть из коробки; на своём VPS поставьте reverse-proxy
  (Caddy/Nginx) с сертификатом.
- Каталог `server/data/` (ключи и база токенов) **не коммитьте** — он в
  `.gitignore`. Делайте его резервную копию: потеря `keys.json` сделает все
  уже выданные лицензии непроверяемыми.

## API

`POST /api/validate` — тело `{"token": "...", "deviceId": "..."}`.
- `200 {"payload": "...", "sig": "...", "exp": 1699999999999}` — токен активен.
- `403 {"error": "invalid_or_disabled"}` — токена нет или он выключен.

Админка (Basic-auth):
- `GET  /admin` — список токенов, создание, вкл/выкл, удаление.
- `GET  /admin/pubkey` — открытый ключ для встраивания в приложение.
