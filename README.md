# Message Sender (Android)

Простое Android-приложение на Kotlin. Пользователь вводит **номер телефона**,
**текст сообщения** и **интервал в секундах** (по умолчанию — 15). После нажатия
«Начать отправку» приложение отправляет это SMS-сообщение на указанный номер
через заданный интервал, пока отправка не будет остановлена.

## Как это работает

- **`MainActivity`** — экран с полями ввода (номер, сообщение, интервал) и
  кнопками «Начать»/«Остановить». Запрашивает разрешение `SEND_SMS` во время
  выполнения.
- **`SmsSenderService`** — foreground-сервис, который циклически отправляет SMS
  через `SmsManager` с заданным интервалом и показывает уведомление с кнопкой
  «Остановить». Работа в foreground-сервисе позволяет продолжать отправку, даже
  когда экран приложения закрыт.
- **`SmsReceiver`** — `BroadcastReceiver` для входящих SMS, который управляет
  автоматическим циклом (без учёта регистра, с любого номера):
  - сообщение со словом **«символ»** → отправка приостанавливается, а
    отправителю уходит ответ **«Ок»**;
  - затем приложение ждёт сообщение со словом **«успешно»** → отправка
    **возобновляется** с теми же параметрами (номер, текст, интервал);
  - цикл повторяется бесконечно, пока пользователь не остановит отправку вручную
    (кнопкой «Остановить» или через уведомление).
- **`SenderState`** — сохраняет последние параметры отправки и флаг активности
  цикла в `SharedPreferences`, чтобы `SmsReceiver` мог возобновить отправку даже
  когда экран приложения закрыт.
- **`LicenseManager` / `LicenseWorker`** — контроль доступа по токену. Приложение
  работает только при действующей лицензии, выданной сервером (см. ниже).

## Контроль доступа по токенам

Функционал приложения включается **только по токену**, который выдаёте вы. Токен
проверяется на вашем сервере, который выдаёт подписанную лицензию на ограниченный
срок; при истечении срока или отключении токена приложение перестаёт работать.

- **Активация.** Пользователь вводит выданный вами токен и жмёт «Активировать».
- **Сервер и админка.** Лежат в каталоге [`server/`](server/README.md): список
  всех токенов с комментариями, счётчик устройств, включение/отключение (отзыв).
- **Отзыв.** Выключаете токен в админке → все устройства с ним отключаются в
  течение срока лицензии (по умолчанию до 24 часов).

Перед сборкой APK задайте в `app/build.gradle.kts` два поля: `SERVER_URL`
(публичный `https`-адрес сервера) и `LICENSE_PUBLIC_KEY` (открытый ключ, который
печатает сервер при запуске). Подробности — в [`server/README.md`](server/README.md).

> Оговорка: абсолютной защиты на устройстве, которое вы не контролируете, не
> бывает — обладатель APK с навыками реверс-инжиниринга теоретически может
> пропатчить проверку. Но для обычных пользователей это надёжный
> контролируемый доступ с быстрым отзывом.

## Сборка

Нужен Android SDK. Создайте файл `local.properties` в корне проекта с путём к SDK:

```
sdk.dir=/путь/к/Android/Sdk
```

Затем соберите APK:

```bash
./gradlew assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.

Установка на подключённое устройство:

```bash
./gradlew installDebug
```

## Требуемые разрешения

- `SEND_SMS` — отправка SMS.
- `RECEIVE_SMS` — приём входящих SMS для распознавания слова «символ».
- `INTERNET` / `ACCESS_NETWORK_STATE` — проверка токена на сервере лицензий.
- `POST_NOTIFICATIONS` (Android 13+) — уведомление foreground-сервиса.
- `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_DATA_SYNC` — фоновая работа.

## Важное предупреждение об ответственном использовании

Отправляйте сообщения **только на номера, которыми вы владеете, или на отправку
которым у вас есть явное разрешение** (например, тестирование собственного
устройства или напоминания самому себе). Массовая или повторяющаяся отправка
сообщений человеку без его согласия является преследованием и в большинстве
стран **незаконна**. Также за каждое SMS оператор может взимать плату по вашему
тарифу.
